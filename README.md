# PGWEB-ACARA-10

WebGIS Persebaran Lokasi OPD Kabupaten Belitung berbasis LeafletJS, PHP, dan MySQL.

## Fitur
- Pilihan Basemap: OpenStreetMap, Esri World Imagery, dan Google Street
- Tool GIS: Pengukuran jarak & luas area (Leaflet Measure), Fullscreen, Scale Bar, Geocoder/Pencarian lokasi, Home extent, Koordinat kursor real-time
- Manajemen Data Spasial & Tabular (CRUD):
  - Menampilkan marker dinamis dari database MySQL (`pgweb_acara9`)
  - Floating modal tabel data atribut dengan fitur pencarian dan *Zoom to Feature*
  - Tambah dan edit data lokasi dengan fitur penentuan koordinat via klik peta
  - Hapus data langsung dari antarmuka WebGIS
